# Instruções para Claude Code

As instruções compartilhadas por agentes estão em
[AGENTS.md](../AGENTS.md). Leia também [COPILOT.md](../COPILOT.md) e siga
as fontes de contexto e specs indicadas por esses arquivos.

Este arquivo é apenas um ponteiro para evitar cópias divergentes. Para
orientações persistentes reconhecidas pelo Claude Code, configure o
`CLAUDE.md` no escopo apropriado conforme a
[documentação de memória](https://code.claude.com/docs/en/memory); não
presuma que este documento em `docs/` seja carregado automaticamente.
